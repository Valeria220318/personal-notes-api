# API REST de Notas Personales

Este proyecto es una API REST sencilla que permite realizar operaciones CRUD (Crear, Leer, Actualizar, Eliminar) sobre notas personales. Fue desarrollado como parte de una actividad práctica para reforzar conceptos básicos de desarrollo backend y diseño de bases de datos.

## 📋 Características

Cada nota contiene la siguiente información:
- Título
- Autor
- Fecha y hora
- Cuerpo de la nota
- Clasificación (personal, laboral, escolar, entre otras)

## 🎯 Objetivo

Permitir que cualquier usuario gestione notas personales mediante solicitudes HTTP a través de endpoints REST, utilizando solo PHP y almacenamiento en archivo plano (`notas.json`).
